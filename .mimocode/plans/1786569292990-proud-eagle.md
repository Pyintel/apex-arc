# Comprehensive Dashboard Rebuild Plan: Forest & Emerald Minimal

This plan outlines the step-by-step rebuild of the Helix dashboard interface to replace the current layout, navigation, and color scheme with a hyper-minimalist, weightless, low-friction, green-themed design system.

---

## 1. Critical Files to Modify

- `src/app/globals.css` — Core theme values, selection colors, transitions, and hover glow effects.
- `src/shared/components/layouts/DashboardLayout.tsx` — Main viewport shell layout.
- `src/shared/components/Sidebar.tsx` — Floating, collapsible left-rail navigation bar.
- `src/shared/components/Header.tsx` — Minimalist single-line header.
- `src/shared/components/Card.tsx` — Borderless, translucent glassmorphism surfaces and cleanup.
- `src/shared/components/TabNav.tsx` — Minimalist, borderless URL tab navigation.
- `src/app/(dashboard)/overview/page.tsx` — Hyper-minimalist grid-based overview dashboard.

---

## 2. Detailed Implementation Steps

### Step 2.1: Reconfigure Theme & Colors (`src/app/globals.css`)
- **Background**: Ensure dark slate-charcoal `#080C0A` is the body color-scheme background.
- **Selection**: Set `::selection` to green: `background-color: rgba(16, 185, 129, 0.22); color: #10B981;`.
- **Shadows & Borders**: Reduce `--shadow-soft` to `none` or a very faint green glow. Remove heavy dark borders, replacing them with translucent borders: `rgba(16, 185, 129, 0.05)`.
- **Typography**: Apply a clean, distinct font weight hierarchy using a tight sans-serif font stack. Remove colored background badge boxes from labels, replacing them with weight hierarchy.
- **Transitions & Glow**: Add global micro-interaction rules. Smooth transitions (150ms) and focus/hover glow effects:
  ```css
  .hover-glow {
    transition: all 150ms ease-in-out;
  }
  .hover-glow:hover {
    box-shadow: 0 0 12px rgba(16, 185, 129, 0.2);
    border-color: rgba(16, 185, 129, 0.3) !important;
  }
  ```

### Step 2.2: Refactor Navigation Sidebar (`src/shared/components/Sidebar.tsx`)
- **Floating Rail Layout**: Place the sidebar in a floating fixed-height position: `fixed left-3 top-3 bottom-3 z-30 flex flex-col rounded-2xl bg-[#080C0A]/40 backdrop-blur-md border border-primary/5 shadow-soft transition-all duration-300 ease-in-out`.
- **Remove Search Box**: Eliminate the search input in the sidebar to clean up visual clutter, relying instead on the Cmd+K command palette first.
- **Collapsed Mode**: When collapsed (`w-16`), show only navigation icons. Ensure that on-hover tooltips render cleanly with a glassmorphism background.
- **Simplified Controls**: Clean up the restart/shutdown buttons at the bottom. Render them as clean, borderless icons.
- **Active Accent**: Ensure active links render in vivid Emerald Green text (`#10B981`) and a subtle background accent (`bg-primary/10`).

### Step 2.3: Rebuild Dashboard Layout Shell (`src/shared/components/layouts/DashboardLayout.tsx`)
- Adjust the grid container. Since the sidebar is floating at `fixed left-3`, adjust the main content padding or left margin (`lg:ml-[232px]` when expanded and `lg:ml-[76px]` when collapsed) to avoid overlapping the float sidebar.
- Keep the design clean by removing any layout dividers.

### Step 2.4: Streamline the Header Component (`src/shared/components/Header.tsx`)
- Set the background to translucent: `bg-transparent` or `bg-[#080C0A]/40 backdrop-blur-md` with `border-transparent` on the bottom.
- Ensure the header is single-line, displaying only:
  - Active status indicator pulse dot (green).
  - Page context title and subtitle in tight typography.
  - Quick Search & Commands (`⌘K`) shortcut trigger button on the right.
  - Minimal language/logout icons without boxes or borders.

### Step 2.5: Rebuild Overview Page (`src/app/(dashboard)/overview/page.tsx`)
Replace the existing page with a minimalist dashboard grid (maximum 3 sections on screen):
1. **Top Metrics Row**: 4 cards showing:
   - System Health (Operational)
   - System Uptime
   - Active Gateway Connections
   - Memory RSS (in MB)
   Add micro-sparklines (simple inline SVG path trendlines) and percentage changes in vivid green text next to values.
2. **Primary Focus Area (Left 70%)**:
   - Renders a clean AreaChart (emerald-green gradient fill, glowing line) of proxy request throughput/volume over time using `useRecharts()`.
   - Renders a clean provider status table of active configured provider nodes.
3. **Action Side-Panel / Feed (Right 30%)**:
   - Streamlined real-time activity feed showing the last 5 logs.
   - Quick actions block: "Clear Cache", "Test All Connections", "Trigger Command Palette".

### Step 2.6: Polish Components & Typography (`src/shared/components/Card.tsx`, `TabNav.tsx`)
- **Card**: Set the card background to `rgba(16, 185, 129, 0.03)` with `border-transparent` or very faint primary borders and `shadow-none`. Remove the duplicate `Card.ListItem` code block.
- **Hover Actions**: Ensure contextual actions inside lists/data rows are displayed cleanly on hover (`group-hover:opacity-100` transition).
- **TabNav**: Wipe bottom borders from the container, replacing them with negative space (24px+ gaps) between elements.
