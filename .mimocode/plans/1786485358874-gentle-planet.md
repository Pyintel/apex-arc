# Plan: Align @packages/web with @packages/opencode TUI Launch Menu & Branding

## Objective
Make `packages/web` match the look and feel of `packages/opencode` TUI launch menu, including:
1. Launch menu / home screen aesthetic (Starry background with twinkling stars and meteors, ASCII shimmer APEX logo, APEX ARC 1.0 / Pyintel Helix branding, centered prompt launcher, TUI-styled recent project list).
2. Pyintel Helix provider integration (`https://api.pyintel.cc/helix`) and provider list configuration.
3. Updated APEX ARC 1.0 branding across titlebar, page titles, and i18n dictionaries.
4. Custom slash commands, skills, and MCP badge support in the prompt popover launcher.

---

## Decision (Unattended Mode)
Selected **ASCII Shimmer Logo** for the Web Home screen to deliver 100% visual parity with the `packages/opencode` TUI launch menu.

## Step-by-Step Implementation Steps

### Step 1: Create Starry Background Component (`packages/web/src/components/starry-background.tsx`)
- Implement a HTML5 Canvas component that renders:
  - Twinkling green star field (`✦`, `✧`, `✶`) matching TUI density (`0.00394`).
  - Periodic meteors shooting at angle $0.36\text{ rad}$ with Braille/pixel sub-pixel trace and glowing core.
  - Smooth animation frame loop (`requestAnimationFrame`) with automatic resize observer.

### Step 2: Create TUI ASCII Shimmer Logo (`packages/web/src/components/tui-logo.tsx`)
- Port `logo` and `logoThin` character matrices from `packages/opencode/src/cli/logo.ts`.
- Port sweep animation and shimmer ring calculations using half-block characters (`▀`, `▄`, `█`).
- Color palette: APEX Green (`rgb(34, 197, 94)`) and Gray (`rgb(160, 160, 160)`).

### Step 3: Redesign Home Screen (`packages/web/src/pages/home.tsx`)
- Combine `<StarryBackground />` (at `zIndex: 0`) and `<TuiLogo />`.
- Add branding text: "APEX by Pyintel • Powered by Pyintel Helix".
- Embed prompt input component directly on home screen for quick slash command / prompt submission.
- Style recent project cards with TUI-inspired dark glass card design.

### Step 4: Register Pyintel Helix Provider & Connection Wizard
- Update `packages/web/src/hooks/use-providers.ts` to include `pyintel-helix`.
- Build `packages/web/src/components/dialog-connect-helix.tsx`:
  - Pre-filled endpoint: `https://api.pyintel.cc/helix`.
  - API Key field (`sk-...`).
  - Model verification via `/v1/models` call.
- Connect `dialog-select-provider.tsx` and `dialog-connect-provider.tsx` to open the Helix setup wizard.

### Step 5: Update Application Branding & Strings
- Update `packages/web/src/components/titlebar.tsx` to display "APEX ARC 1.0".
- Update `packages/web/src/i18n/en.ts` dictionary with updated `app.name.desktop` and Helix provider entries.

### Step 6: Enhance Custom Slash Commands Popover (`packages/web/src/components/prompt-input/slash-popover.tsx`)
- Add visual badge tags (`custom`, `skill`, `mcp`) beside slash command triggers.
- Ensure custom user-created commands from global sync are correctly highlighted and selectable.
