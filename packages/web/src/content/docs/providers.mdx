This 9Router-only build exposes a single bundled provider: **9Router**.

Use `/connect` to store your 9Router API key.

Other connectors that used to ship with the app are documented in [Integrations](/docs/integrations).

---

### Credentials

When you add the 9Router API key with the `/connect` command, it is stored
in `~/.local/share/opencode/auth.json`.

---

### 9Router

9Router is the only built-in provider in this build.

1. Run the `/connect` command in the TUI and select **9Router**.

   ```txt
   /connect
   ```

2. Paste your 9Router API key.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

3. Start chatting with the 9Router model.

:::note
The default 9Router endpoint is `https://api.pyintel/helix`. Set `NINE_ROUTER_BASE_URL` if your deployment uses a different host.
:::

---

### Archived connectors

The following connector families are archived in this build and no longer appear in the app:

1. External model providers such as Anthropic, OpenAI, Azure OpenAI, Amazon Bedrock, OpenRouter, GitHub Copilot, GitLab, Cloudflare, Vercel, Google, Mistral, Cohere, Perplexity, xAI, and other provider integrations.
2. Local and remote MCP servers.
3. Custom connector/login flows that previously created third-party provider entries.

If you need one of those connectors for a custom build, re-enable it in `provider` or `mcp` in your local config and add the matching auth/plugin wiring back into the app.
